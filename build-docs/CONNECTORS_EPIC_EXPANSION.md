Every connector configuration includes:
1. ✅ Detailed description
2. ✅ Specific capabilities list
3. ✅ 4-5 real use cases
4. ✅ Setup complexity rating
5. ✅ Estimated setup time
6. ✅ Step-by-step API key instructions (5-7 steps each)
7. ✅ Important notes and warnings
8. ✅ Troubleshooting tips (where applicable)
9. ✅ Required permissions
10. ✅ Transparency information (what data is accessed, stored, frequency)
11. ✅ Link to official documentation
12. ✅ Icon and brand color
13. ✅ Category assignment
