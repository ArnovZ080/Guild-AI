## 📝 Usage Example

### Connecting to a Platform
```python
from guild.src.integrations import project_management

# Add credentials
project_management.add_project_credentials(
    platform="asana",
    api_key="your_api_key_here",
    workspace_id="your_workspace_id"
)

# Validate connection
async with project_management.AsanaConnector(credentials) as connector:
    is_valid = await connector.validate_connection()
    
# Get data
tasks = await connector.get_tasks()
```

### Using the API
```bash
# List all connectors
curl http://localhost:8000/api/connectors/

# Validate credentials
curl -X POST http://localhost:8000/api/connectors/validate/asana \
  -H "Content-Type: application/json" \
  -d '{"platform": "asana", "api_key": "your_key"}'

# Get tasks
curl http://localhost:8000/api/connectors/project-management/asana/tasks
```
